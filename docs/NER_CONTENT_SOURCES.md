# North Eastern regional content and image sources

Verified for MVP-10 on 6 September 2026. All 32 items are bundled editorial English copy, written for calm reminiscence. Sources were inspected during implementation; this is a source-based factual check, not endorsement or independent review by the source organizations. Native-speaker and community review remain outstanding.

## Editorial approach

Use government tourism/cultural institutions and RIWATCH Museum for narrow, checkable claims. Omit unsupported origins, symbolism, superlatives, clinical claims, political history and tourist sales copy. Prompts invite optional reflection and never assert personal experience. Different communities within a state are not treated as interchangeable. Dzükou is explicitly described as a shared Nagaland–Manipur border landscape. These are four examples per state, not exhaustive cultural representation.

Cultural text and image descriptions are English. All controls, categories, recovery, language disclosure and state context use the existing seven-language catalog. UI translations follow current project conventions and need regional linguistic review.
